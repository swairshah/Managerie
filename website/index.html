Manage a menagerie of coding agents.

If you are running a handful of agents in terminal, this is for you. Managerie watches over all of them: it chimes when one finishes and needs you, jumps you to the exact terminal, and lets you reply without leaving what you're doing right now.

How it works

🔔

Chimes only when it matters

The ding means a session finished and is waiting for you. Mid-turn chatter, tool runs, and status flips stay silent. Pick your chime — Pop, Glass, Hero, or fourteen others.

↗

Jump to the exact terminal

Click a notification or a session row and Managerie focuses the right window, tab, and tmux pane — Ghostty, iTerm2, tmux, zellij, it finds the one.

🎙

Reply from anywhere

Type a reply into any session from the dropdown, or hold the mic and speak — Apple's on-device recognizer transcribes it and injects it into the agent's terminal. No API keys, nothing leaves your Mac.

Install

Install with Homebrew

brew install --cask swairshah/tap/managerie — signed & notarized. Launch it and allow notifications when asked.

Connect your agents

Open the window → Integrations → one click per agent. It installs the pi extension, claude-code hooks, and codex notify for you — and can remove them just as cleanly.

Restart your agent sessions

New sessions check in automatically. That's it — go start something long-running and wander off.

Daily driving

What it feels like

  • An agent finishes → chime + notification. Click it to land in that terminal.
  • The menubar dropdown shows every session with its last message — click a card to expand, type a reply, or hold the mic and dictate.
  • Session order is stable — rows never shuffle while agents work.
  • Pipe anything into the notification stream from scripts: echo "backup done" | mnote
  • Dictation runs on-device — no API keys, no audio leaves your Mac.
